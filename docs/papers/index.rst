Papers and citation
===================

JAXNS v3
--------

Joshua G. Albert (2026),
`Phantom-Conditioned Nested Sampling <https://arxiv.org/abs/2609.32120>`_,
arXiv:2609.32120.

Read and cite this preprint for the current JAXNS algorithm. It provides a
deeper explanation of the race-tree formulation, plateau handling, phantom
conditioning, and evidence-improving and posterior-improving allocation,
together with experiments examining their benefits and limitations.

Earlier papers
--------------

The previous paper,
`Phantom-Powered Nested Sampling <https://arxiv.org/abs/2312.11330>`_
(Albert, 2023), is redacted. Use the v3 paper for phantom conditioning.

The original paper,
`JAXNS: a high-performance nested sampling package based on JAX
<https://arxiv.org/abs/2012.15286>`_ (Albert, 2020), remains valid as a
reference for JAXNS's high performance. Its description of the algorithm is
now superseded by the v3 paper.
